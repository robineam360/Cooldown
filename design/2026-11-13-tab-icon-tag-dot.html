7 · Colour-blind simulation — deuteranopia and protanopia

Viénot / Brettel linear matrices (what Chrome's rendering emulation uses), applied to whole panels, so the provider marks shift too. The six-provider strip and the three-accent row for D1-R, D1-V, with D2 and F as controls.

Read-out: D1-R keeps its two dots apart in both simulations (red → dark ochre, blue stays blue) — it is the one hue pair that survives; D1-R's green variant fails against red. D1-V's violet and teal both land on blue and are told apart by lightness only. D2 and F are unchanged (ink and shape carry no hue). A colour dot therefore has to be Robin's pair, and its red is the alert red.

8 · Settings — where two dot colours would be chosen (only for D1)

Appearance gains a row "Tag colours" after Theme (Android: bold bodyLarge title, bodySmall note, the two current swatches inline; iOS: a row with the two swatches and a chevron). It opens a page with two rows, "Personal" and "Work", each the current 24 dp swatch and its name; tapping one opens the same six-column grid the account accent uses, limited to the eleven themes (no provider colours, no Material You) and "Reset to defaults". A swatch that is some account's accent carries that account's name under it ("Teams") — a warning, not a block. May a dot colour equal an account accent? Yes: forbidding it would make the two colours depend on which accents exist, and the 1.5 dp cleared ring still separates the dot (§6 shows what it looks like). Defaults: Work #FF3B30, Personal #1A73E8 if Robin's pair; #00838F / #7E57C2 if mine. My answer: no picker at all — two fixed tokens in `spec/core` §5 if colour wins, a row only if someone asks; a colour nobody can change is a colour the row glyph, chip and filter can match.

11 · Alternatives I think better

  1. F — the built figure badge, everywhere. One drawing, one vocabulary with the rows and chips, no pair to choose, no rule change, no Settings row, colour-blind-safe; cost: the Android port and the iOS spike.
  2. D2 — ink dot, filled Work / ring Personal. If a dot is wanted: shape carries the tag, the rule stands, nothing else changes; cost: a dot to learn (the rows teach person / briefcase, not dot / ring).
  3. D3 — a dot only on Work accounts. Fewest marks, Personal marks untouched, "dot = Work" is one sentence; cost: breaks the no-empty-slot model the rows follow (every row shows a glyph).
