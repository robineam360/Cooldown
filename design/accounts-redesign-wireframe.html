CCRM-65 · Accounts Redesign · rev D · 2026-09-11

A shorter, cleaner account card

Robin's brief: "The Accounts tab in settings is just too long… put the usage dashboard on the same line as the Re-sign in / Clear buttons. Make all these three actions clear with an icon."

Decisions from rev A review (2026-09-11):

  • Details moves off the status line entirely — no chevron. It's the first item ("Details…") in the ⋮ menu, and opens as a dialog.
  • Action row stays icon + label beneath (rev A shape); variants B (icon-only) and C (outlined pills) are dropped.
  • Token tail stays out of the header, in Details, as drawn.
  • The amber "expires soon" line now fires at ≤3 days, not ≤7.
  • ChatGPT's third cell keeps the "Settings" label; the status line stays relative-only.
  • Fix: the ChatGPT mark now matches the Claude mark's optical size (CCBG-23 (Mark Size Mismatch)).
  • Active indicator: B green dot (decided 2026-09-11).
  • Dot placement: immediately after the label, 8px gap; the plan chip follows the dot; the flexible spacer moves after the chip (decided 2026-09-11).

6. What changes, what doesn't

Removed from the card

  • Anthropic status / OpenAI status links — become an error-notice-only surfaced via MainActivity, not a permanent link on every card.
  • The divider between the buttons and the links.
  • Four always-on lines (auto-renews-in, last-auto-renewed, expiry, added) — move into the ⋮ menu's Details dialog.
  • The token tail from the header — moves into the Details dialog.
  • ChatGPT's own Refresh button — replaced by the shared ↻ on the status line, same control Claude uses.
  • The absolute clock time on the status line — status line is relative-only; the clock time is the dialog's first line.
  • The status-line chevron — Details is now the first item ("Details…") in the ⋮ menu, opened as a dialog, instead of an inline expand.
  • The "Active" pill — replaced by an 8dp green dot after the label (and a red dot in the same slot for "Needs re-auth"); no chip, no visible word.

Unchanged

  • The ⋮ menu's other items (Rename…, Accent colour…, Remove account) and their dialogs.
  • Sign-in flows (browser sign-in, device-code sheet for ChatGPT).
  • The Add account sheet.
  • The two-column switch at 700dp.

Accessibility: the dot is decorative to a sighted user but not to TalkBack — since the word "Active" is no longer on screen, the dot's view carries contentDescription "Active" (green) or "Needs re-auth" (red), read out with the account name and plan the same way the pill's text used to be.
