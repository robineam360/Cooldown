# Cooldown app icon · Shared pace

The selected design is option 01 from the C study. Use [shared-pace.svg](shared-pace.svg) as the artwork master for Android, iOS, iPadOS, macOS, Windows and future Linux icons. The [preview](shared-pace-preview.png) shows the rounded tile from the study.

Three clockwise arcs form an open C. The red radial line marks even usage for the elapsed portion of the quota period. The outer Claude arc is terracotta up to that line. Only its excess segment switches to the same red as the marker. The middle ChatGPT arc meets the line and the inner Gemini arc stops short. Preserve the dark separation around the marker so the line remains visible beside the red arc.

The SVG separates the opaque plate from the mark. Fit the complete mark as a unit when preparing platform assets. Apply platform masks or transparent outer margins during export. For Android adaptive artwork, center and scale the mark inside the foreground safe zone and use the plate colour for the background layer. Check the C opening, three arcs, and red tip at small launcher and desktop sizes.
