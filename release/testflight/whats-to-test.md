# What to Test — Cooldown 2.0 (iPhone and iPad)

Cooldown shows how much of your Claude, ChatGPT and Gemini usage windows you have used, and when
they reset. This is the first iPhone and iPad build. It reads usage only: it never sends a prompt
and never spends quota.

**Please try**
1. **Sign in** (Settings → Add account) to Claude, ChatGPT or Gemini. Claude asks you to paste a code
   back; ChatGPT shows a short code to approve on a device you already use; Gemini opens Google's
   sign-in. Tell me if any step is confusing.
2. **The main screen:** each account's Weekly bar and 5h ring, the pace mark, the trend chart (tap
   it), and the All summary tab when you have two or more accounts.
3. **Widgets:** add a Number, Bars, Strip or Overview widget to the Home Screen, and a lock-screen
   widget. They update when iOS lets them, so a few minutes' delay is normal.
4. **Reset alerts** (Settings → Reset alerts): leave one on and see whether it arrives when a window
   resets.
5. **Live Activity** (Settings → Lock Screen) and the **Control Center** control.
6. **iPad:** the sidebar, rotation, and Split View.

**Known gaps in this build**
- Network and server errors are not shown as messages yet; the card just keeps its last reading.
- History has no Plan Fit block, and the iPad History screen is one column.
- The share card still leads with 5h.
- Widgets may show a stale reading until the app has been opened; iOS decides when they refresh.

**Feedback:** reply to the TestFlight invitation email, or use *Send Beta Feedback* (screenshot, then
Share). A note on what you expected and what you saw is the most useful thing.
